# Implicit sequence learning under dual-tasking

Source: Röttger, Zhao, Gaschler & Haider (2021), *Journal of Cognition*, Experiment 1. doi:10.5334/joc.136

## Research question

**What, and why.** Implicit sequence learning: people pick up a repeating
order of events, but much less so during a second task. Why? The idea tested:
events of the two tasks that occur together are bound, so the sequence can be
learned only where it is predictable which events occur together.

**How.** A serial reaction time task with a hidden eight-element sequence,
trained alongside a tone task in which half of the elements always come with
the same tone. Learning is tested afterwards without the tones: slower
responses in random-order blocks than in the sequence block show learning.

**Part used.** That test for the elements with a fixed tone.
